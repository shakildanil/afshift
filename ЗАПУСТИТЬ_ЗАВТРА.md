# ⏰ ЗАПУСТИТЬ ЗАВТРА УТРОМ

## 🎯 Что нужно сделать

### ЗАВТРА (когда обновится лимит AppsFlyer API)

Запустите одну команду:

```bash
python update_october_november.py
```

Это:
1. ✅ Получит реальные данные из AppsFlyer за октябрь и ноябрь
2. ✅ Заполнит листы `AF_Stats_Октябрь25` и `AF_Stats_Ноябрь25`
3. ✅ Revenue будет реальный из Event Revenue (300к+ руб)
4. ✅ Все источники с правильными названиями и разделением iOS/Android

## ⚠️ Почему сейчас нет данных

**Достигнут дневной лимит запросов к AppsFlyer API** из-за тестирования:
```
You've reached your maximum number of in-app event reports that can be downloaded today
```

Лимит обновляется в 00:00 UTC (примерно в 03:00 по Москве).

## 📊 Что проверить

После запуска завтра проверьте листы:
- `AF_Stats_Октябрь25` - должно быть ~943 депозита, Revenue 300к+ руб
- `AF_Stats_Ноябрь25` - данные за начало месяца

## 🔧 Альтернативные команды

```bash
# Если нужно обновить только октябрь:
python update_fonbet_stats.py --year 2025 --month 10

# Если нужно обновить только ноябрь:
python update_fonbet_stats.py --year 2025 --month 11

# Для автоматического ежедневного обновления:
```
