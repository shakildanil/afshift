# ⏰ ЗАПУСТИТЬ ЗАВТРА УТРОМ

## 🎯 Что нужно сделать

### ЗАВТРА (когда обновится лимит AppsFlyer API)

Запустите одну команду:

```bash
python update_october_november.py
```

Это:
1. ✅ Получит реальные данные из AppsFlyer за октябрь и ноябрь
2. ✅ Заполнит листы `AF_Stats_Октябрь25` и `AF_Stats_Ноябрь25`
3. ✅ Revenue будет реальный из Event Revenue (300к+ руб)
4. ✅ Все источники с правильными названиями и разделением iOS/Android
5. ✅ **НОВОЕ:** Для `mintegral_int` и `unity_int` в iOS будет детализация по кампаниям

## 🆕 Новая фича: Детализация по кампаниям

Для источников `mintegral_int` и `unity_int` в iOS теперь будет отображаться:

**Основная строка:**
```
mintegral_int  iOS  15000₽  $520.00  $505.00  3.37%  120  120  3
```

**Детализация по каждой кампании:**
```
  └─ Adc_test         $300.00  $300.00       70   70
  └─ Another_camp     $150.00  $150.00       35   35
  └─ Test_camp        $70.00   $70.00        15   15
```

Это позволит быстро анализировать, какая кампания приносит больше FTD и Revenue!

## ⚠️ Почему сейчас нет данных

**Достигнут дневной лимит запросов к AppsFlyer API** из-за тестирования:
```
You've reached your maximum number of in-app event reports that can be downloaded today
```

Лимит обновляется в 00:00 UTC (примерно в 03:00 по Москве).

## 📊 Логика сбора статистики

✅ **Event Time (время события af_ftd):** текущий месяц
✅ **Install Time (время установки):** текущий + прошлый месяцы (максимум 30 дней назад от события)

Это означает:
- Собираются события (FTD), которые произошли в текущем месяце
- Но установка приложения могла быть в текущем или прошлом месяце (в пределах 30 дней)
- Это корректная атрибуция для анализа конверсии install → FTD
