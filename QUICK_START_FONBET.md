## 🔍 Как это работает

1. **Получает данные из AppsFlyer** - события `af_ftd` за месяц
2. **Фильтрует** - только депозиты где `event_time - install_time < 30 дней`
3. **Группирует** - по источнику (Media Source) и платформе (iOS/Android из названий кампаний)
4. **Загружает расходы** - из существующих листов (если есть колонка Spend)
5. **Считает** - Revenue из AppsFlyer, Profit = Revenue - Spend, ROI = Profit/Spend*100
6. **Записывает** - в лист с названием месяца (например, "Октябрь25")

## 💡 Важно

- **Spend данные** загружаются из существующих листов автоматически
- Если Spend нет - будет 0, Profit = Revenue, ROI = #DIV/0!
- **Платформа** определяется из названий кампаний (ios/aos в названии)
- **Источники** очищаются от суффиксов (_int, _ios, _android)
