# Сводка проекта

## 🎯 Задача

Создать скрипт для автоматизации заполнения статистики Фонбета из AppsFlyer в Google Sheets с ежедневным обновлением в 10:00.

## ✅ Что реализовано

### 1. Основной функционал

- ✅ **AppsFlyer API Integration**
  - Подключение к AppsFlyer Raw Data Export API v5
  - Получение in-app events (af_ftd) для iOS и Android приложений
  - Парсинг CSV данных
  - Обработка множественных App IDs

- ✅ **Обработка данных**
  - Фильтрация событий по правилу: `event_time - install_time < 30 дней`
  - Группировка по Media Source и Campaign
  - Подсчет депозитов (каждая строка = 1 депозит)
  - Создание сводных отчетов

- ✅ **Google Sheets Integration**
  - OAuth 2.0 аутентификация
  - Автоматическое создание и обновление листов
  - Форматирование данных в табличный вид
  - Обновление за весь месяц (с 1-го числа до вчерашнего дня)

- ✅ **Планировщик задач**
  - Ежедневный автоматический запуск в 10:00
  - Настраиваемое время через конфигурацию
  - Логирование всех операций
  - Обработка ошибок

### 2. Тестирование

- ✅ **41 тест** с покрытием 62%
  - Unit тесты для всех компонентов
  - Integration тесты для проверки взаимодействия
  - Mock тесты для внешних зависимостей
  - Тесты на граничные случаи

```python

days_difference = event_time - install_time
valid = days_difference < 30  # строго меньше 30 дней
```

### 2. Подсчет депозитов

```python
# Каждая строка в CSV = 1 депозит
# Группировка по (Media Source, Campaign)
```

### 3. Обновление данных

```python
# Обновляется весь месяц:
```
