# Использование скрипта обновления статистики Фонбет

## 🎯 Основное правило

**Скрипт НЕ изменяет существующие листы!**

Создается **отдельный лист** с префиксом `AF_Stats_` для статистики из AppsFlyer.

## 📋 Примеры использования

### Базовое использование

```bash
# Обновление за октябрь 2025
# Создаст лист "AF_Stats_Октябрь25"
python update_fonbet_stats.py --year 2025 --month 10
```

### Обновление за текущий месяц

```bash
# Создаст лист типа "AF_Stats_Октябрь25" (зависит от текущей даты)
python update_fonbet_stats.py
```

### Тестовый режим

```bash
# Создаст лист "AF_Stats_Тест"
python update_fonbet_stats.py --test
```

### С загрузкой Spend из существующих листов (опционально)

```bash
# Если нужно загрузить Spend из существующих листов
python update_fonbet_stats.py --year 2025 --month 10 --load-spend
```

**По умолчанию Spend НЕ загружается** - будут нулевые значения, Profit = Revenue.

## 📊 Структура создаваемого листа

Лист `AF_Stats_Октябрь25` будет содержать:

| Source | Platform | Spend $ | Revenue $ | Profit $ | ROI % | Deposits | Campaigns |
|--------|----------|---------|-----------|----------|-------|----------|-----------|
| mintegral | iOS | $0,00 | $1 481,48 | $1 481,48 | #DIV/0! | 15 | 3 |
| ironsource | Android | $0,00 | $27 222,22 | $27 222,22 | #DIV/0! | 23 | 5 |
| ... | ... | ... | ... | ... | ... | ... | ... |
| **Total** | | **$0,00** | **$794,960.00** | **$794,960.00** | **#DIV/0!** | **943** | |

**Примечание:** Spend = $0,00 по умолчанию (если не использовать `--load-spend`)

## 🔍 Как это работает

1. **Получает данные из AppsFlyer** - события `af_ftd` за месяц
2. **Фильтрует** - только депозиты где `event_time - install_time < 30 дней`
3. **Группирует** - по источнику и платформе (iOS/Android из названий кампаний)
4. **Создает НОВЫЙ лист** - с префиксом `AF_Stats_`
5. **Записывает статистику** - Spend, Revenue, Profit, ROI, Deposits, Campaigns

## ⚠️ Важно

- ✅ **Существующие листы НЕ изменяются**
- ✅ **Создается отдельный лист** для AppsFlyer статистики
- ✅ **Spend по умолчанию = 0** (если не использовать `--load-spend`)
- ✅ **Profit = Revenue** (если Spend = 0)
- ✅ **ROI = #DIV/0!** (если Spend = 0)

## 📝 Названия листов

Скрипт создает листы с названиями:
- `AF_Stats_Октябрь25` (октябрь 2025)
- `AF_Stats_Ноябрь25` (ноябрь 2025)
- `AF_Stats_Декабрь25` (декабрь 2025)
- `AF_Stats_Тест` (в тестовом режиме)

## 🚀 Автоматический запуск

Для ежедневного обновления:

```bash
python src/scheduler.py
```

Это будет создавать/обновлять лист за текущий месяц каждый день в 10:00.
