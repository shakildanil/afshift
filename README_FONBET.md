# Обновление статистики Фонбет в Google Sheets

## 🎯 Что делает скрипт

1. **Получает данные из AppsFlyer** по событиям `af_ftd` для приложения `ru.bkfon-Android`
2. **Фильтрует события** (только депозиты где `event_time - install_time < 30 дней`)
3. **Группирует по источникам** (Media Source) с учетом платформы (iOS/Android из названий кампаний)
4. **Загружает данные о расходах** из существующих листов (если есть)
5. **Заполняет Google Sheets** статистикой: Spend, Revenue, Profit, ROI

## 📊 Структура данных

Скрипт создает таблицу со следующими колонками:
- **Source** - название источника (без суффиксов _int, _ios и т.д.)
- **Platform** - платформа (iOS, Android, all)
- **Spend $** - расходы (из существующих листов или 0)
- **Revenue $** - доход (из AppsFlyer)
- **Profit $** - прибыль (Revenue - Spend)
- **ROI %** - рентабельность (Profit / Spend * 100)
- **Deposits** - количество депозитов
- **Campaigns** - количество уникальных кампаний

## 🚀 Использование

### Базовое использование

```bash
# Обновление за текущий месяц
python update_fonbet_stats.py

# Обновление за конкретный месяц
python update_fonbet_stats.py --year 2025 --month 10

# Тестовый режим (создает лист "Тест")
python update_fonbet_stats.py --test

# Без загрузки данных о расходах
python update_fonbet_stats.py --no-spend
```

### Примеры

```bash
# Обновить статистику за октябрь 2025
python update_fonbet_stats.py --year 2025 --month 10

# Тестовый запуск (создаст лист "Тест")
python update_fonbet_stats.py --test

# Обновить без данных о расходах
python update_fonbet_stats.py --no-spend
```

## 📋 Названия листов

Скрипт автоматически создает листы с названиями типа:
- `Октябрь25` (для октября 2025)
- `Ноябрь25` (для ноября 2025)
- и т.д.

В тестовом режиме создается лист `Тест`.

## 🔍 Как работает группировка

### Определение платформы

Платформа определяется из названия кампании:
- Если в названии есть `ios`, `_ios`, `-ios` → **iOS**
- Если в названии есть `aos`, `android`, `_aos` → **Android**
- Иначе → **all**

### Названия источников

Из Media Source убираются суффиксы:
- `mintegral_int` → `mintegral`
- `unity_ios` → `unity`
- `ironSource_android` → `ironSource`

## 💰 Данные о расходах (Spend)

Скрипт пытается загрузить данные о расходах из существующих листов:
1. Ищет листы с ключевыми словами: `spend`, `расход`, `бюджет`
2. Если не находит, берет первый несистемный лист
3. Парсит колонки: Source, Platform, Spend
4. Использует эти данные для расчета Profit и ROI

Если данных о расходах нет, Spend = 0, Profit = Revenue, ROI = #DIV/0!
