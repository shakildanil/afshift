Это:
1. Получит **реальные данные** из AppsFlyer за октябрь и ноябрь
2. Создаст/обновит листы:

   - Deposits (количество депозитов)
   - И Total с правильной суммой

## 📊 Как это работает

### Revenue считается правильно:

```
Event Revenue в AppsFlyer уже содержит стоимость каждого депозита в рублях
Например:
- Событие 1: Event Revenue = 100 руб
- Событие 2: Event Revenue = 500 руб  
- Событие 3: Event Revenue = 100 руб
ИТОГО для кампании: 100 + 500 + 100 = 700 руб
```

Код просто **суммирует Event Revenue** из всех событий для каждого источника.
