# Чеклист запуска проекта

## ✅ Перед первым запуском

### 1. Подготовка окружения

- [ ] Python 3.12+ установлен
- [ ] Создано виртуальное окружение (`python -m venv venv`)
- [ ] Виртуальное окружение активировано
- [ ] Зависимости установлены (`pip install -r requirements.txt`)

### 2. Конфигурация AppsFlyer

- [ ] API ключ AppsFlyer получен (уже есть в задании)
- [ ] iOS App ID получен и добавлен в `.env` (опционально)
- [ ] Android App ID проверен (`ru.bkfon-Android`)

### 3. Конфигурация Google Sheets

- [ ] Создан проект в Google Cloud Console
- [ ] Google Sheets API включен
- [ ] OAuth 2.0 credentials созданы (Desktop app)
- [ ] Файл `credentials.json` скачан и размещен в корне проекта
- [ ] ID Google таблицы проверен в `.env`

### 4. Проверка настроек

- [ ] Запущен `python setup_google_credentials.py`
- [ ] Все файлы на месте
- [ ] Тесты проходят (`pytest`)

## ✅ Первый запуск

### Тестовый запуск

- [ ] Запущен `python run_once.py`
- [ ] Открылся браузер для авторизации Google
- [ ] Авторизация прошла успешно
- [ ] Файл `token.json` создан
- [ ] Данные получены из AppsFlyer
- [ ] Google Sheets обновлен
- [ ] В таблице появился новый лист с данными

### Проверка результата

- [ ] Открыта Google таблица
- [ ] Лист с текущим месяцем создан
- [ ] Данные корректны (есть Media Source, Campaign, Депозиты)
- [ ] Дата обновления указана
- [ ] Статистика по приложениям отображена

## ✅ Настройка автозапуска

### Windows

- [ ] Task Scheduler открыт
- [ ] Задача создана
- [ ] Триггер настроен (при запуске системы / ежедневно)
- [ ] Действие указано (`python run_scheduler.py`)
- [ ] Рабочая папка указана
- [ ] Задача протестирована

### Linux

- [ ] Systemd service файл создан
- [ ] Service активирован (`systemctl enable`)
- [ ] Service запущен (`systemctl start`)
- [ ] Статус проверен (`systemctl status`)
- [ ] Логи проверены (`journalctl -u fonbet-stats -f`)

## 📝 Заметки

### Для первого запуска:

**Обязательно:**
1. Установить зависимости
2. Настроить Google Sheets API
3. Провести тестовый запуск

**Рекомендуется:**
1. Запустить все тесты
2. Изучить документацию
3. Настроить автозапуск

**Опционально:**
1. Настроить уведомления
2. Настроить мониторинг
3. Создать backup

### Частые ошибки:

1. **Забыли активировать venv** → `venv\Scripts\activate` (Windows)
2. **Не установили зависимости** → `pip install -r requirements.txt`
3. **Нет credentials.json** → Создать в Google Cloud Console
4. **Неправильный API ключ** → Проверить в `.env`
5. **Нет прав на таблицу** → Добавить права в Google Sheets

### Команды для быстрой проверки:

```bash
# Проверка установки
pip list

# Проверка тестов
pytest

# Проверка Google Sheets
python setup_google_credentials.py

# Тестовый запуск
python run_once.py

# Проверка конфигурации
python -c "from src.config import config; print(config.validate())"
```
