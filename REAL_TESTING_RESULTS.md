## ⚠️ Что нужно сделать

### Единственное требование: Активный токен AppsFlyer

**Текущий токен:** Неактивен (возвращает "Inactive token")

**Что делать:**

1. **Получите новый токен:**
   ```
   AppsFlyer Dashboard → Settings → API Access → Pull API
   ```
   - Создайте новый токен
   - Убедитесь, что он имеет права на "Export Data"
   - Убедитесь, что он активен

2. **Обновите токен:**
   ```bash
   # В файле .env
   APPSFLYER_API_KEY=ваш_новый_активный_токен
   ```

3. **Проверьте:**
   ```bash
   python test_token_check.py
   ```
   
   Если токен активен, вы увидите:
   ```
   SUCCESS! Токен работает корректно!
   ```

4. **Запустите:**
   ```bash
   python run_once.py
   ```
